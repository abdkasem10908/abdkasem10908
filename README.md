# Cybersecurity & Network Security Glossary

A concise reference of key security terms, written by a networking
engineering student to explain how threats relate to network layers.

## 📚 Contents
| Term | Category | OSI Layer |
|------|----------|-----------|
| Phishing | Social Engineering | Application (7) |
| SQL Injection | Web Attack | Application (7) |
| XSS | Web Attack | Application (7) |
| Malware | Malicious Software | Multiple |

## 🎯 Purpose
Help beginners understand common attacks and how
network defenses (firewalls, IDS/IPS, segmentation) mitigate them.

- Protocols: TCP/IP, DNS, DHCP, HTTP/HTTPS
- Routing & Switching: OSPF, VLANs, Subnetting
- Tools: Cisco Packet Tracer, Wireshark, GNS3
- Security: Firewalls, ACLs, VPN basics
